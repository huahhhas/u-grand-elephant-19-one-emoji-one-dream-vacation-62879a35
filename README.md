# One Emoji, One Dream Vacation

Exactly one emoji for the dream vacation — a desert island, 🏝️ — written to `/output/entry.txt` by a pure-stdlib Python program. One glyph: island, palm and sea, the faraway escape in a single postcard.

> 🏝️

## Run it

```sh
python3 main.py
```

This writes the emoji to `/output/entry.txt` (or to the path in `OUTPUT_DIR`).
